Structure definition
Not to be confused with Structure file.

This feature is exclusive to Java Edition.
 There is a related tutorial page for this topic!
See Tutorial:Custom structures.
A structure is a large decoration, covering an area up to 256×256×256 block centered on the structure start. Structures often consist of multiple pieces that are fit together to form the overall structure. They are configured using JSON files within a data pack in the path . To generate in a world, a structure needs to be part of at least one structure set. data/<namespace>/worldgen/structure

Structure types
Structures use different types. The structure types and their corresponding configuration are listed below:

Using Jigsaw Blocks
Main article: Jigsaw structure
Jigsaw structures are using template pools and jigsaw blocks and allow full customization of structure generation using a datapack.
