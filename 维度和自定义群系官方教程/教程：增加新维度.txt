维度

新创造的维度。

使用实验设置打开世界时出现的警告界面。
添加新维度只需在数据包中创建一个文件即可。这个第一维度通过块生成器添加了一个新的超平坦世界。flat

data/tutorial/dimension/example_world.json

{
  "type": "minecraft:overworld",
  "generator": {
    "type": "minecraft:flat",
    "settings": {
      "biome": "minecraft:plains",
      "layers": [
        {
          "block": "minecraft:stone",
          "height": 64
        }
      ],
      "structure_overrides": []
    }
  }
}
复制
在添加现有世界时，一定要离开并重新打开世界！警告界面会让你用实验性世界设置确认。这意味着新版本可能会毫无预警地破坏现有的世界生成数据包。你可以点击“我知道自己在做什么！”。

维度类型
上述示例使用了 。这是对该维度的维度类型所指的。尺寸由两部分组成："type": "minecraft:overworld"

尺寸类型控制环境属性。维度类型的更改也会影响现有区块。
区块生成器控制放置在世界中的物理方块和实体。对区块生成器的更改只会影响新生成的区块。
如果你想修改维度属性，可以在文件夹里创建一个新文件。在这个例子中dimension_type[Int] min_y 和[Int]高度属性与主世界维度类型相比进行了修改。这些控制着维度的建造限制。

噪声发生器

一个用噪声块生成器实现的自定义维度，完全是平原。
为了在自定义维度中拥有类似世界地图的地形，可以使用生成器类型。noise

data/tutorial/dimension/example_world.json

{
  "type": "tutorial:example_world",
  "generator": {
    "type": "minecraft:noise",
    "settings": "minecraft:overworld",
    "biome_source": {
      "type": "minecraft:fixed",
      "biome": "minecraft:plains"
    }
  }
}
复制

噪声布线

表面规则

世界底部的基岩垂直梯度。

草块下方有一层泥土。
目前唯一的地表方块是方解石和草地方块。你可以在草块下方加一层泥土，在世界底部加一层基岩渐变，配合更复杂的表面规则。

data/tutorial/worldgen/noise_settings/example_world.json

{
  // ...
  "surface_rule": {
    "type": "minecraft:sequence",
    "sequence": [
      {
        "type": "minecraft:condition",
        "if_true": {
          "type": "minecraft:vertical_gradient",
          "random_name": "minecraft:bedrock_floor",
          "true_at_and_below": {
            "above_bottom": 0
          },
          "false_at_and_above": {
            "above_bottom": 5
          }
        },
        "then_run": {
          "type": "minecraft:block",
          "result_state": {
            "Name": "minecraft:bedrock"
          }
        }
      },
      {
        "type": "minecraft:condition",
        "if_true": {
          "type": "minecraft:stone_depth",
          "offset": 0,
          "surface_type": "floor",
          "add_surface_depth": false,
          "secondary_depth_range": 0
        },
